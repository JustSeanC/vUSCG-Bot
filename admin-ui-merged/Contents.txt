## What the source audit established

| Observed path | Candidate behavior and limits |
| --- | --- |
| Admin status, legacy direct service calls and Discord | Shared native `PirepService::review()` rereads the row from the primary under `FOR UPDATE`. Same-state and stale revision requests return the current record with zero accounting writes. New terminal transitions rotate the receipt. Discord passes no revision and can only review a submitted pending report. TLS, request/signature validation, clock window and nonce handling are unchanged. |
| ACARS file, manual submit and auto-reject | The audited API keeps filing attributes, custom fields, fares, route fallback, SimBrief attachment and the synchronous `PirepFiled` event in one transaction. The temporary filing marker distinguishes an unfinished split filing from a previously submitted pending report. DisposableBasic runs before rank auto-approval. A direct rejection by its synchronous listener records one native rejection event, with no acceptance credit. Other callers of `file`, `submit` and `PirepFiled` need inventory. |
| Divert, bid, leave status and native lifecycle events | The observed subscribers remain synchronous and run under the filing lock. Reviewed broadcasts use an after-commit callback. The actual SimBrief, diversion, fleet/vmsACARS and status-model event implementations need verification. Existing diversion and rejection location policies are retained. Rejecting an accepted report subtracts counts/minutes and reruns native rank policy. It does not automatically rewind position, fuel or a previously awarded credential. |
| Admin CRUD, ACARS field/route writes and cron | Accounting inputs on accepted records require a rejection before editing or deletion. Admin creation cannot enter ACCEPTED directly. Edits rotate the revision. Cron rechecks age, status, state and revision before deleting. ACARS filing and edits recheck write conditions under the row lock. The audited positional/log endpoints primarily append telemetry and do not set PIREP state. Independently installed telemetry subscribers remain in scope for the staging audit. |
| Pilot and aircraft recount | Both installed recount services write accounting counters. They lock the affected participant and establish a new consistent read after locking, with no earlier transaction snapshot. Concurrent review uses PIREP → pilot → aircraft. Recount locks only its target participant and uses ordinary aggregate reads of committed PIREPs, avoiding a reverse PIREP row lock. `FlightService`’s inspected ACCEPTED reference is a read. |
| Finance and awards | Installed subscribers execute synchronously. The candidate retains that order and transaction. The audited explicit API finance recalculation now locks the accepted PIREP. Installed finance service, journal repositories, award plug-ins and their connections/queues were not supplied, so rollback and idempotency of installed ledger and award writes are still unproven. |
| Emails and broadcast | Defer only the reviewed filed, accepted, rejected, status, state, award, rank and diversion notification sends. Event-time attributes are captured before deferring. Existing registration verification and registration webhook handling are preserved. The callback logs a failed delivery without retrying accounting. It is best-effort across process crashes. A durable delivery outbox and per-channel idempotency policy require actual notification classes, queue configuration and provider capabilities. |

No service automatically reruns a native transaction after a deadlock or lock timeout. The bridge reports busy on a direct MySQL lock conflict. The existing Discord transport reconciles uncertain responses with a newly signed status request. A nested caller must unwind the enclosing transaction if a nested state operation throws. The fixture includes MySQL’s nested lock-timeout exception behavior and outer transaction rollback. Site-defined exception handling is still a staging check.

## Shutdown and rollback

Keep the bridge closed and stop new state decisions, filing and relevant workers before changing code. Drain transactions and record the affected PIREP IDs, receipts, counters, ledger, awards and queued notifications. For an authorized staging rollback, restore the previous exact PHP files and admin assets together; the two additive columns can remain for reconciliation. Disable or isolate still-pending notification jobs before reloading workers. Review already committed effects case by case before correcting the ledger or totals. Restoring a previous code build cannot reverse those effects. Require an approved reconciliation and backup restore plan before any destructive database change or production action.

## Maintenance window, failures and recovery

- MySQL DDL commits implicitly. 005 can rebuild or lock the training records table. 002/003 can affect the CGAS tables. Each 007 ALTER builds an index on an existing native pivot and can block writers, take disk space or rebuild a table. Measure impact with representative staging data, confirm free space and obtain a maintenance window. Even additive 004/006/008 can wait on metadata locks of referenced tables.
- After failure, leave workers stopped. Save the exact submitted statement/error and inspect the selected schema with the preflight and `SHOW CREATE TABLE`. Check whether a timed-out import is still running with the staging operator. 005 must show both the generated column and the unique index. 007 may have succeeded on only a subset of pivots. Apply only the missing complete statement after verification. If a table has only part of a statement's intended shape, stop and review its definition and data before using any corrective DDL.
- A 5.7 schema that previously used the root 004 or 006 may contain rows with no corresponding guards. The alternate files deliberately stop on those existing tables. Preserve rows, inventory and reconcile invalid records offline, and use a separately reviewed recovery or approved restore before proceeding. Repeatable CREATE/seed statements do not repair an incorrect definition.
- For rollback, restore the previous reviewed bot/module files and configuration only when compatible with the retained schema. Keep queues, history, ownership markers, bridge nonces and backups. Resolve partial native deliveries with the visible audit trail. A database restore requires an approved plan for changes since the snapshot and a proven restore into a separate schema first. +namespace App\Services;
+
+use Illuminate\Database\Eloquent\Model;
+use Illuminate\Support\Facades\Log;
+use Throwable;
+
+final class PirepAfterCommit
+{
+    public static function notify(Model $context, string $kind, callable $send): void
+    {
+        $connection = $context->getConnection();
+        if ($connection->transactionLevel() === 0) {
+            $send();
+
+            return;
+        }
+
+        $id = $context->getKey();
+        $connection->afterCommit(static function () use ($kind, $id, $send): void {
+            try {
+                $send();
+            } catch (Throwable $error) {
+                // Never turn a committed accounting operation into a reported failure.
+                Log::warning('Post-commit notification failed', [
+                    'kind' => $kind, 'record_id' => $id, 'exception_type' => get_class($error),
+                ]);
+            }
+        });
+    }

function race(string $first, string $second, array $winner, array|string $loser, string $secondId = 'report1'): void {

    expectSame(line($holder), 'holding', 'First writer owns the transaction');
    $follower = child($second, $secondId);
    try {
        expectSame(line($follower), 'ready', 'Second writer opened competing transaction');
        if ($second === 'timeout') {
            expectSame(line($follower), $loser, 'Second writer timed out without replay');
        } else {
            $read = [$follower[1]];
            $write = $except = null;
            expectSame(stream_select($read, $write, $except, 0, 200_000), 0, 'Second writer is blocked on a shared lock');
        }
    } finally {
        touch($release);
    }
    expectSame(json_decode(line($holder), true), $winner, 'First outcome');
    if ($second !== 'timeout') {
        expectSame(json_decode(line($follower), true), $loser, 'Second outcome');
    }
    finishChild($holder);
    finishChild($follower);
    unlink($release);
}

        ?int $timestamp = null,
        ?string $nonce = null,
        ?string $key = null

        $body = json_encode($payload, JSON_THROW_ON_ERROR);

            'HTTPS' => 'on',
            'HTTP_ACCEPT' => 'application/json',
            'CONTENT_TYPE' => 'application/json',
            'HTTP_X_VUSCG_TIMESTAMP' => (string) $timestamp,
            'HTTP_X_VUSCG_NONCE' => $nonce,
            'HTTP_X_VUSCG_SIGNATURE' => $signature,
        ], $body);
    }

use App\Services\PirepService;
use Illuminate\Database\QueryException;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Log;
use JsonException;
use Modules\VuscgCustom\Services\PirepDecisionGate;

class PirepReviewController
{
    private const CLOCK_WINDOW = 60;

    public function status(Request $request): JsonResponse
    {
        return $this->handle($request, false);
    }

    public function decision(Request $request): JsonResponse
    {
        return $this->handle($request, true);
    }

    private function handle(Request $request, bool $decision): JsonResponse
    {
        if (!$request->isSecure() || $request->getQueryString() !== null) {
            return response()->json(['code' => 'unauthorized'], 401);
        }
        $body = $request->getContent();
        if (strlen($body) > 1024) {
            return response()->json(['code' => 'too_large'], 413);
        }

        $timestamp = $request->header('X-VUSCG-Timestamp', '');
        $nonce = $request->header('X-VUSCG-Nonce', '');
        $signature = $request->header('X-VUSCG-Signature', '');
        $secret = config('vuscg_pirep_review.secret');
        $now = time();
        if (!is_string($secret) || !preg_match('/\A[a-f0-9]{64}\z/', $secret)
            || !preg_match('/\A[0-9]{10}\z/', $timestamp)
            || abs($now - (int) $timestamp) > self::CLOCK_WINDOW
            || !preg_match('/\A[a-f0-9]{32}\z/', $nonce)
            || !preg_match('/\A[a-f0-9]{64}\z/', $signature)) {
            return response()->json(['code' => 'unauthorized'], 401);
        }

        $signed = implode("\n", [$request->method(), $request->getBaseUrl().$request->getPathInfo(),
            $timestamp, $nonce, $body]);
        if (!hash_equals(hash_hmac('sha256', $signed, $secret), $signature)) {
            return response()->json(['code' => 'unauthorized'], 401);
        }

        $connection = (new Pirep())->getConnection();
        $reserved = $connection->table('vuscg_pirep_review_nonces')->insertOrIgnore([
            'nonce' => $nonce,
            'expires_at' => (int) $timestamp + self::CLOCK_WINDOW,
        ]);
        if ($reserved !== 1) {
            return response()->json(['code' => 'replay'], 401);
        }

        try {
            $payload = json_decode($body, true, 8, JSON_THROW_ON_ERROR);
        } catch (JsonException) {
            return response()->json(['code' => 'invalid'], 422);
        }

        $id = $payload['pirep_id'] ?? null;
        if (!is_string($id) || !preg_match('/\A[A-Za-z0-9_-]{1,64}\z/', $id)) {
            return response()->json(['code' => 'invalid'], 422);
        }

        if (!$decision) {
            if (count($payload) !== 1) {
                return $this->result('invalid', $id, null, 422);
            }
            $pirep = Pirep::query()->useWritePdo()->whereKey($id)->first();
            if (!$pirep || $pirep->getKey() !== $id) {
                return $this->result('not_found', $id, null, 404);
            }
            return is_int($pirep->state)
                ? $this->result('status', $id, $pirep->state)
                : $this->result('disabled', $id, null, 503);
        }

        $action = $payload['action'] ?? null;
        $reviewer = $payload['reviewer'] ?? null;
        $discordId = $reviewer['discord_id'] ?? null;
        $pilotNumber = $reviewer['pilot_number'] ?? null;
        if (count($payload) !== 3 || !in_array($action, ['approve', 'reject'], true)
            || !is_array($reviewer) || count($reviewer) !== 2 || !array_key_exists('pilot_number', $reviewer)
            || !is_string($discordId) || !preg_match('/\A[0-9]{17,20}\z/', $discordId)
            || ($pilotNumber !== null && (!is_string($pilotNumber) || !preg_match('/\AC[0-9]{1,15}\z/', $pilotNumber)))) {
            return $this->result('invalid', $id, null, 422);
        }

        // A separate reviewed release is required before production may ever write.
        $protocol = PirepService::class.'::VUSCG_REVIEW_PROTOCOL';
        if (!PirepDecisionGate::allows(app()->environment(), config('vuscg_pirep_review.decisions_enabled'),
            defined($protocol) ? constant($protocol) : null)) {
            return $this->result('disabled', $id, null, 503);
        }

        $target = $action === 'approve' ? PirepState::ACCEPTED : PirepState::REJECTED;
        try {
            // No revision means pending-only. The native service owns all accounting locks.
            [$pirep, $changed] = app(PirepService::class)->review($id, $target);
        } catch (QueryException $error) {
            if (!in_array((int) ($error->errorInfo[1] ?? 0), [1205, 1213], true)) {
                throw $error;
            }
            return $this->result('busy', $id, null, 503);
        }
        if (!$pirep) {
            return $this->result('not_found', $id, null, 404);
        }
        $state = $pirep->state;
        if (!$changed && $state === PirepState::PENDING) {
            return $this->result('busy', $id, null, 503);
        }
        if ($changed && $state !== $target) {
            throw new \RuntimeException('Native PIREP service returned an unexpected state.');
        }
        [$code, $status] = $changed ? ['changed', 200] : ['not_pending', 409];

        if ($code === 'changed') {
            Log::info('vUSCG PIREP review committed', [
                'pirep_id' => $id, 'state' => $state, 'discord_id' => $discordId, 'pilot_number' => $pilotNumber,
            ]);
        }
        return $this->result($code, $id, $state, $status);
    }

    private function result(string $code, string $id, ?int $state, int $status = 200): JsonResponse
    {
        return response()->json(['code' => $code, 'pirep_id' => $id, 'state' => $state], $status);
    }
}

    }

const { createHmac, randomBytes } = require('node:crypto');
const fetch = require('node-fetch');

const validPirepId = id => typeof id === 'string' && /^[A-Za-z0-9_-]{1,64}$/.test(id);

function createPirepBridge({
  baseUrl = process.env.PIREP_BRIDGE_URL,
  secret = process.env.PIREP_BRIDGE_SECRET,
  fetchImpl = fetch,
  timeout = 5000,
} = {}) {
  async function request(operation, payload) {
    let url;
    try {
      url = new URL(baseUrl);
      if (url.protocol !== 'https:' || url.username || url.password || url.search || url.hash ||
          !/^[a-f0-9]{64}$/.test(secret ?? '')) throw new Error();
    } catch {
      return { code: 'unconfigured' };
    }

    url.pathname = url.pathname.replace(/\/$/, '') + '/api/vuscgcustom/pirep-review/' + operation;
    const body = JSON.stringify(payload);
    const timestamp = String(Math.floor(Date.now() / 1000));
    const nonce = randomBytes(16).toString('hex');
    const signature = createHmac('sha256', secret)
      .update(['POST', url.pathname, timestamp, nonce, body].join('\n')).digest('hex');
    const signal = AbortSignal.timeout(timeout);
    try {
      const response = await fetchImpl(url.toString(), {
        method: 'POST', body, signal, redirect: 'error', size: 4096,
        headers: {
          'Content-Type': 'application/json', Accept: 'application/json',
          'X-VUSCG-Timestamp': timestamp, 'X-VUSCG-Nonce': nonce, 'X-VUSCG-Signature': signature,
        },
      });
      if ([401, 403].includes(response.status)) return { code: 'unauthorized' };
      if (response.status === 429) return { code: 'busy' };
      const result = await response.json();
      if (result.pirep_id !== payload.pirep_id) return { code: 'uncertain' };
      if (response.status === 404 && result.code === 'not_found') return { code: 'not_found' };
      if (response.status === 422 && result.code === 'invalid') return { code: 'invalid' };
      if (response.status === 503 && ['disabled', 'busy'].includes(result.code)) return { code: result.code };
      if (!Number.isInteger(result.state) || result.state < 0 || result.state > 7) return { code: 'uncertain' };
      if (operation === 'status' && response.ok && result.code === 'status') return result;
      if (operation === 'decision' && response.status === 409 && result.code === 'not_pending' &&
          result.state !== 1) return result;
      const expected = payload.action === 'approve' ? 2 : 6;
      if (operation === 'decision' && response.ok && result.code === 'changed' &&
          result.state === expected) return result;
      return { code: 'uncertain' };
    } catch {
      return { code: 'uncertain' };
    }
  }

  return {
    async decide(pirepId, action, reviewer) {
      if (!validPirepId(pirepId) || !['approve', 'reject'].includes(action)) return { code: 'invalid' };
      const decision = await request('decision', { pirep_id: pirepId, action, reviewer });
      if (decision.code !== 'uncertain') return decision;
      const status = await request('status', { pirep_id: pirepId });
      if (status.code === 'status') return { code: 'reconciled', state: status.state };
      if (status.code === 'not_found') return status;
      return decision;
    },
  };
}

module.exports = { createPirepBridge, validPirepId };

const fs = require('fs');
const { createHash } = require('node:crypto');
const { createPirepBridge, validPirepId } = require('./pirepBridge');
const { PIREP_STATE, reportUrl, readReport, reportState } = require('./pirepEvidence');
const { postToTrainingThread } = require('./training/threads');
const { EmbedBuilder, ActionRowBuilder, ButtonBuilder, ButtonStyle } = require('discord.js');

const CACHE_PATH = './pending_pireps_cache.json';

function loadCache() {
  try {
    return Object.assign(Object.create(null), JSON.parse(fs.readFileSync(CACHE_PATH, 'utf8')));
  } catch {
    return Object.create(null);
  }
}

function saveCache(obj) {
  try {
    fs.writeFileSync(CACHE_PATH + '.tmp', JSON.stringify(obj, null, 2));
    fs.renameSync(CACHE_PATH + '.tmp', CACHE_PATH);
  } catch (e) {
    console.warn('⚠️ Could not write pending PIREP cache:', e?.message ?? e);
  }
}

function formatMinutesHHMM(totalMinutes) {
  const m = Math.max(0, parseInt(totalMinutes, 10) || 0);
  const h = Math.floor(m / 60);
  const mm = String(m % 60).padStart(2, '0');
  return `${String(h).padStart(2, '0')}:${mm}`;
}

function aircraftStatusLabel(code) {
  const c = String(code || '').toUpperCase();
  return (
    {
      A: 'Active',
      M: 'Maintenance',
      S: 'Stored',
      R: 'Retired',
      C: 'Scrapped',
    }[c] || 'Unknown'
  );
}

function pirepStateLabel(state) {
  const s = Number(state);
  return (
    {
      [PIREP_STATE.PENDING]: 'Pending',
      [PIREP_STATE.ACCEPTED]: 'Approved',
      [PIREP_STATE.REJECTED]: 'Rejected',
      [PIREP_STATE.DELETED]: 'Deleted',
    }[s] || `State ${s}`
  );
}

function buildPendingEmbed(rec, pirepUrl, vatsimStatsUrl) {
  const pilotLine = `**C${rec.pilot_id}** — ${rec.pilot_name || 'Unknown Name'}`;
  const acLine =
    rec.registration
      ? `**${rec.registration}** (${rec.aircraft_icao || 'Unknown'}) — **${rec.aircraft_status || '?'}** (${aircraftStatusLabel(rec.aircraft_status)})`
      : `Aircraft ID: **${rec.aircraft_id || 'Unknown'}**`;

  const submittedTs = rec.submitted_ts ? Number(rec.submitted_ts) : Math.floor(Date.now() / 1000);

  const timeHHMM = formatMinutesHHMM(rec.flight_time);
  const distNm =
    rec.distance != null && !Number.isNaN(Number(rec.distance))
      ? `${Number(rec.distance).toFixed(0)} NM`
      : '—';

  return new EmbedBuilder()
    .setTitle('🕓 Pending PIREP (Approval Required)')
    .addFields(
      { name: 'Pilot', value: pilotLine, inline: false },
      { name: 'Aircraft', value: acLine, inline: false },
      { name: 'Dep / Arr', value: `**${rec.dpt_airport_id} → ${rec.arr_airport_id}**`, inline: true },
      { name: 'Time', value: `**${timeHHMM}**`, inline: true },
      { name: 'Distance', value: `**${distNm}**`, inline: true },
      { name: 'Source', value: `**${rec.source_name || 'Unknown'}**`, inline: true },
      { name: 'Submitted', value: `<t:${submittedTs}:F>  (<t:${submittedTs}:R>)`, inline: false },
      { name: 'Links', value: `• View PIREP: ${pirepUrl}\n• VATSIM Stats: ${vatsimStatsUrl ?? 'Not on file'}`, inline: false }

    )
    .setFooter({ text: `PIREP: ${rec.pirep_id}` });
}

function buildButtons(pirepId, pirepUrl) {
  return new ActionRowBuilder().addComponents(
    new ButtonBuilder()
      .setCustomId(`pirep:approve:${pirepId}`)
      .setLabel('Approve')
      .setStyle(ButtonStyle.Success),
    new ButtonBuilder()
      .setCustomId(`pirep:reject:${pirepId}`)
      .setLabel('Deny')
      .setStyle(ButtonStyle.Danger),
    new ButtonBuilder()
      .setLabel('View')
      .setStyle(ButtonStyle.Link)
      .setURL(pirepUrl)
  );
}

async function fetchPendingPireps(db) {
  const sql = `
    SELECT
      p.id AS pirep_id,
      p.user_id,
      p.aircraft_id,
      p.dpt_airport_id,
      p.arr_airport_id,
      p.flight_time,
      p.distance,
      p.source_name,
      UNIX_TIMESTAMP(p.submitted_at) AS submitted_ts,

      u.pilot_id,
      u.name AS pilot_name,

      (SELECT IF(COUNT(*) = 1, MIN(dl.discord_id), NULL)
         FROM discord_links dl WHERE dl.pilot_id = u.pilot_id) AS discord_id,

      ufv.value AS vatsim_cid,

      a.registration,
      a.icao AS aircraft_icao,
      a.status AS aircraft_status

    FROM pireps p
    JOIN users u
      ON u.id = p.user_id

    LEFT JOIN aircraft a
      ON a.id = p.aircraft_id

    LEFT JOIN user_field_values ufv
      ON ufv.user_id = u.id
     AND ufv.user_field_id = 1

    WHERE p.state = ? AND p.deleted_at IS NULL
    ORDER BY p.submitted_at DESC
    LIMIT 50
  `;

  const [rows] = await db.query(sql, [PIREP_STATE.PENDING]);
  return rows || [];
}


function resolvedMessage(message, id, state, baseUrl, reviewer) {
  const title = `PIREP Resolved — ${pirepStateLabel(state)}`;
  const original = message.embeds?.[0];
  const embed = EmbedBuilder.from(original ?? new EmbedBuilder()).setTitle(title)
    .setColor(state === PIREP_STATE.ACCEPTED ? 0x2ecc71 : 0xe74c3c);
  const footer = original?.title === title ? original.footer?.text : null;
  embed.setFooter({ text: reviewer ? `PIREP: ${id} • Reviewed by ${reviewer}` : footer || `PIREP: ${id}` });

  const row = new ActionRowBuilder();
  if (state === PIREP_STATE.ACCEPTED) row.addComponents(
    new ButtonBuilder().setCustomId(`pirep-training:${id}`).setLabel('Record Training').setStyle(ButtonStyle.Primary)
  );
  const url = reportUrl(id, baseUrl);
  if (url) row.addComponents(new ButtonBuilder().setLabel('View').setStyle(ButtonStyle.Link).setURL(url));
  return { embeds: [embed], components: row.components.length ? [row] : [], allowedMentions: { parse: [] } };
}

async function reconcileCache({ client, db, cache, pirepBaseUrl }) {
  for (const [id, entry] of Object.entries(cache)) {
    if (!validPirepId(id) || !entry?.channelId || !entry?.messageId) {
      delete cache[id];
      continue;
    }
    try {
      const state = reportState(await readReport(db, id));
      if (state === PIREP_STATE.PENDING) continue;
      const channel = await client.channels.fetch(entry.channelId);
      const message = await channel.messages.fetch(entry.messageId);
      await message.edit(resolvedMessage(message, id, state, pirepBaseUrl));
      delete cache[id];
      saveCache(cache);
    } catch (error) {
      // A retry after a transient error or restart edits the same message.
      if ([10003, 10008].includes(error.code)) delete cache[id];
      else console.warn('Could not reconcile a PIREP review:', error.code || error.name);
    }
  }
}

async function tickWatcher(opts) {
  const { client, db, guildId, trainingChannelId, pirepBaseUrl, vatsimStatsBaseUrl, fallbackChannelId } = opts;
  const cache = loadCache();
  await reconcileCache({ client, db, cache, pirepBaseUrl });
  saveCache(cache);

  const pending = await fetchPendingPireps(db);
  const guild = guildId ? await client.guilds.fetch(guildId).catch(() => null) : client.guilds.cache.first();
  if (!guild) return;
  const parent = await guild.channels.fetch(trainingChannelId).catch(() => null);

  for (const rec of pending) {
    const id = String(rec.pirep_id);
    const url = reportUrl(id, pirepBaseUrl);
    if (!url || cache[id]) continue;

    const cid = (rec.vatsim_cid || '').trim();
    const stats = /^\d{6,8}$/.test(cid) ? `${vatsimStatsBaseUrl.replace(/\/$/, '')}/${cid}` : null;
    const nonce = createHash('sha256').update('pirep-review:' + id).digest('hex').slice(0, 25);
    const payload = {
      embeds: [buildPendingEmbed(rec, url, stats)], components: [buildButtons(id, url)], nonce, enforceNonce: true,
    };
    let message;
    try {
      message = await postToTrainingThread(parent, { pilotId: rec.pilot_id, discordId: rec.discord_id }, {
        ...payload, content: 'IPs: trainee filed a PIREP that needs review.',
      });
    } catch (error) {
      // A send with an uncertain result must not also post to the fallback channel.
      console.warn('Could not post a PIREP review in its training thread:', error.code || error.name);
      continue;
    }
    if (!message && fallbackChannelId) {
      const channel = await guild.channels.fetch(fallbackChannelId).catch(() => null);
      if (channel?.isTextBased()) message = await channel.send({ ...payload, allowedMentions: { parse: [] } });
    }
    if (message) {
      cache[id] = { channelId: message.channelId ?? message.channel?.id, messageId: message.id };
      saveCache(cache);
    }
  }
}

function startPendingPirepWatcher(opts) {
  const pollSeconds = Math.max(30, Number(opts.pollSeconds || 60));
  let running = false;
  async function tick() {
    if (running) return;
    running = true;
    try {
      await tickWatcher(opts);
    } catch (error) {
      console.warn('Pending PIREP watcher tick failed:', error.code || error.name);
    } finally {
      running = false;
    }
  }
  void tick();
  setInterval(tick, pollSeconds * 1000);
}

async function handlePirepButton(ctx) {
  const { interaction, db, roles, bridge = createPirepBridge() } = ctx;
  const reply = content => interaction.reply({ content, ephemeral: true });
  const [, action, pirepId, ...extra] = String(interaction.customId || '').split(':');
  const footer = interaction.message.embeds?.[0]?.footer?.text;
  if (extra.length || !validPirepId(pirepId) || !['approve', 'reject'].includes(action) ||
      !interaction.client.user?.id || interaction.message.author?.id !== interaction.client.user.id ||
      !(footer === `PIREP: ${pirepId}` || footer?.startsWith(`PIREP: ${pirepId} • Reviewed by `))) {
    return reply('❌ This review button is unavailable or does not match its PIREP.');
  }

  await interaction.deferUpdate();
  const member = await interaction.guild.members.fetch({ user: interaction.user.id, force: true }).catch(() => null);
  if (!member || ![roles.INSTRUCTOR_PILOT_ROLE_ID, roles.COMMAND_STAFF_ROLE_ID].some(id => id && member.roles.cache.has(id))) {
    return interaction.followUp({ content: '❌ Your permission to review PIREPs could not be verified.', ephemeral: true });
  }
  const reviewer = { discord_id: interaction.user.id, pilot_number: null };
  try {
    const [links] = await db.query(`SELECT u.pilot_id FROM discord_links d
      JOIN users u ON u.pilot_id = d.pilot_id WHERE d.discord_id = ? LIMIT 1`, [reviewer.discord_id]);
    const pilotId = String(links[0]?.pilot_id ?? '');
    if (/^[0-9]{1,15}$/.test(pilotId)) reviewer.pilot_number = 'C' + pilotId;
  } catch {
    console.warn('Could not look up the Discord PIREP reviewer’s linked pilot number.');
  }

  const result = await bridge.decide(pirepId, action, reviewer);
  const resolved = Number.isInteger(result.state) && result.state !== PIREP_STATE.PENDING;
  if (!resolved) {
    const explanation = {
      not_found: 'The PIREP was not found.',
      invalid: 'The bridge rejected the PIREP ID or request.',
      unauthorized: 'The bridge rejected authentication.',
      busy: 'The review is temporarily busy.',
      disabled: 'Approval through Discord is disabled.',
      reconciled: 'The PIREP was still pending at the last check. The original request may still be running.',
    }[result.code] ?? 'The bridge is unavailable or the outcome could not be confirmed.';
    return interaction.followUp({
      content: `❌ ${explanation} Check the PIREP in the native phpVMS admin interface before taking action.`,
      ephemeral: true,
    });
  }

  let state = result.state;
  try {
    if (state === PIREP_STATE.ACCEPTED) {
      state = reportState(await readReport(db, pirepId));
      if (state === PIREP_STATE.PENDING) throw new Error('Acceptance is not yet visible in the bot database');
    }
    const reviewer = result.code === 'changed' && state === result.state ? interaction.user.tag : null;
    await interaction.editReply(resolvedMessage(interaction.message, pirepId, state, undefined, reviewer));
  } catch {
    return interaction.followUp({
      content: `phpVMS reported ${pirepStateLabel(result.state)}. The review message will reconcile once the persisted state can be shown.`,
      ephemeral: true,
    });
  }
}
